# Workflow LN-IA — Séance 08

## Fil directeur

1. **Besoin réel** : définir la difficulté concrète.
2. **Cadrage** : identifier cible, critères et format.
3. **Prompt** : écrire une consigne exploitable.
4. **Production** : obtenir puis conserver V1.
5. **Contrôle humain** : cocher explicitement les huit critères ; vérifier les faits via des sources appropriées.
6. **Correction** : transformer V1 en V2, noter qui a corrigé quoi et pourquoi.
7. **Documentation** : renseigner les limites et préparer l'oral.
8. **Preuve** : conserver les versions, la grille, les sources et la décision humaine.

## Points d'arrêt qualité

- **P1 — Sources absentes :** afficher « non vérifié » ; ne pas affirmer que le résultat est exact.
- **P2 — Données sensibles :** anonymiser avant dépôt public et avant appel au modèle IA.
- **P3 — Corrections non documentées :** statut « à compléter ».
- **P4 — Erreur importante :** statut « à revoir », publication bloquée jusqu'à résolution.
- **P5 — Publication :** une validation de build ne vaut pas validation du contenu pédagogique.
