## Mission

Assister la maintenance pédagogique et technique d'un site **Vite / JavaScript natif** sur le contrôle des productions IA.

1. `README.md`
2. `docs/COMMENCER-ICI.md`

## Règles

- Ne jamais remplacer les archives de `sources-originales/`.
- Les fichiers sources présentent des conflits Git historiques. Ne pas copier leurs marqueurs dans le code actif.
- Préserver l'identité LN-IA et l'attribution au formateur.
- Toute démonstration est fictive et doit rester signalée comme telle.
- Le site est statique et **n'effectue aucun appel à un service IA**.
- Les statuts calculés reflètent uniquement la complétude des formulaires ; la validation réelle est humaine.
- Ne pas committer de données personnelles de candidats.
- Ne pas publier, pousser, créer un commit ni fusionner de branche sans autorisation explicite.
- Documenter les tests réellement effectués ; ne pas annoncer une compilation non exécutée.
- Tester la navigation, les contrôles, les exports Markdown, les pages mobiles et le déploiement.

## Critères de réussite

Une intervention est terminée lorsque les changements sont revus, les tests possibles ont été lancés et documentés, et les points non vérifiés ont été explicitement listés.
